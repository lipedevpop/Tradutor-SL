Instalador para Windows com o ícone oficial e atalhos na área de trabalho e no menu Iniciar.

- Inclui os componentes necessários; dispensa a instalação manual de Python.
- Mantém as configurações e a chave DeepL salvas pelas versões anteriores.
- Inclui atualização pelo aplicativo e restauração da versão anterior.
- Permite desinstalar pelo Windows, preservando os dados pessoais separados.

reinstalação, atalhos e desinstalação do EXE em uma pasta de teste.
